Результаты сравнительного теста Qwen3 TTS на CPU

Модель Qwen/Qwen3-TTS-12Hz-0.6B-CustomVoice, голос Serena. Один и тот же текст, один прогрев и три измеряемых запроса в каждой серии. Измерено полное время ответа API на самом сервере, включая формирование WAV.

2 потока: среднее время 41.15 с, средний RTF 4.384.
4 потока: среднее время 39.06 с, средний RTF 4.296.
Снижение среднего времени ответа 5.08%, снижение среднего RTF 2.01%.

Настройки четырёх потоков согласованы в torch.set_num_threads, OMP_NUM_THREADS и MKL_NUM_THREADS. Во всех шести измеряемых запросах получены непустые WAV-файлы. Это короткий функциональный эксперимент, а не подтверждение длительной стабильности.

Длительность речи меняется между запусками. Изменение времени API частично связано с длиной сформированного аудио. Три повтора на одном тексте не доказывают устойчивого прироста; RTF измеряет отношение полного времени API к длительности аудио. GPU, RAM и энергопотребление в этом эксперименте не измерялись. Равенство качества речи не доказано; необходима отдельная проверка прослушиванием. GPU-замеры из прежнего стенда в данное сравнение не включены.
